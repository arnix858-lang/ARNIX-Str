# ARNIX Cinema — изменения

- Каталог, главная страница, поиск и карточки работают через TMDB.
- Все видеопровайдеры и потоки переведены на Lampac.
- Подключены агрегирующие маршруты /lite/events и /lifeevents.
- Добавлено сопоставление TMDB ID с IMDb и КиноПоиском через /externalids.
- HDRezka-парсер и отдельный HDRezka backend удалены.
- Сохранён встроенный ExoPlayer для воспроизведения найденных потоков.
