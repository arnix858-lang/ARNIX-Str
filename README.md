# ARNIX Cinema

Android-приложение для Android Phone и Android TV на Kotlin + Jetpack Compose.

## Возможности первого этапа
- Русскоязычный интерфейс
- Главная: тренды, популярные фильмы и сериалы
- Каталоги фильмов и сериалов
- Поиск TMDB
- Страница подробной информации
- Избранное в памяти текущего сеанса
- Навигация с поддержкой фокуса Android TV
- GitHub Actions для сборки debug APK

## Настройка TMDB API
Ключ не хранится в репозитории.

Локально создайте `local.properties` в корне проекта и добавьте:
`TMDB_API_KEY=ваш_ключ`

Для GitHub Actions добавьте repository secret с именем `TMDB_API_KEY`.

## Сборка
Требуется JDK 17 и Android SDK 35. Сборка через GitHub Actions запускается автоматически после push.
Локально: `gradle :app:assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Важно
TMDB предоставляет метаданные и изображения, но не видеопотоки. Для просмотра нужны отдельные законные источники видео. Для публичного приложения рекомендуется держать TMDB-ключ на сервере: ключ, встроенный в APK, можно извлечь.


## Состояние сборки
Workflow `Android APK` автоматически запускается при каждом push в `main`. Для наполнения каталога необходимо задать секрет `TMDB_API_KEY` в настройках Actions репозитория.
