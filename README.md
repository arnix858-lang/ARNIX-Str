# ARNIX Cinema

Android-приложение для Android Phone и Android TV на Kotlin + Jetpack Compose.

## Архитектура

- **TMDB** — каталог, главная страница, поиск, постеры, описания, рейтинги и сезоны.
- **Lampac** — единая система поиска видеопровайдеров и получения потоков.
- **ExoPlayer / Media3** — воспроизведение найденных потоков.
- HDRezka-парсер и отдельный HDRezka backend удалены из проекта.

## Lampac

По умолчанию используется сервер:

`https://arnix-lampac-test.onrender.com`

Приложение вызывает:
- `/lite/events` — параллельная проверка источников по TMDB ID;
- `/lifeevents` — получение результатов проверки;
- `/externalids` — сопоставление TMDB с IMDb и КиноПоиском;
- `/lite/{provider}` — получение вариантов видео у выбранного провайдера.

Источники не ограничены Rezka: приложение показывает провайдеры, которые Lampac вернул как доступные. Если один источник не дал ссылку, можно выбрать другой.

## TMDB API key

В GitHub откройте **Settings → Secrets and variables → Actions** и добавьте secret:

- Name: `TMDB_API_KEY`
- Value: Ваш API key v3 от TMDB

GitHub Actions передаёт ключ в BuildConfig при сборке APK. Если ключ отсутствует, сборка всё равно может пройти, но каталог TMDB в приложении не загрузится.

**Важно:** добавление или изменение secret не меняет уже опубликованный APK. После изменения `TMDB_API_KEY` нужно запустить новую сборку Android APK; новый ключ попадёт только в APK, собранный после этого изменения.

## Сборка

Каждый push в `main` запускает workflow **Android APK**.
APK публикуется в GitHub Releases и в артефактах workflow.

## Важно

- Render Free может засыпать после простоя, поэтому первый запрос к Lampac иногда занимает больше времени.
- Доступность конкретных провайдеров зависит от их собственных серверов, географии, ограничений и настроек Lampac.
- Наличие провайдера в списке не гарантирует, что у него есть рабочий поток для каждого фильма.
- TMDB предоставляет только метаданные и изображения, а не видеопотоки.
